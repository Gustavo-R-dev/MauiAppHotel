# 🏨 Hotel App

Aplicativo desenvolvido para gerenciamento e cálculo de reservas de hotel.

---

## 📱 Telas do Aplicativo

### 1. Cálculo da Diária
Permite ao usuário configurar os detalhes da hospedagem:
* Seleção da quantidade de adultos e crianças.
* Escolha da suíte/acomodação desejada.
* Definição do período de estadia (datas de *Check-in* e *Check-out*).

### 2. Tela "Sobre"
Tela informativa desenvolvida para exibir os detalhes do aplicativo:
* Nome do App e Versão (v1.0).
* Créditos ao desenvolvedor.
* Ano de lançamento.

---

### 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Framework:** .NET MAUI
* **Controle de Versão:** Git e GitHub
